# Billing ERP — marketing site

A static site for Billing ERP, built with Astro. The home page introduces the product. Each module has its own page. A floating WhatsApp button opens a chat with +91 95915 91783.

## Run it

```bash
npm install
npm run dev
```

Open the address Astro prints, usually http://localhost:4321.

## Build

```bash
npm run build
npm run preview
```

The static files land in `dist/`. Upload that folder to any static host.
